# Historical verification reports

This directory contains milestone reports, benchmark evidence, diagnostic logs
and audit records from earlier Majoris Image development passes. These reports
are preserved for traceability; they are **not** the authoritative description
of the current source tree or release status.

Their original source-path examples and historical line numbers may refer to
the layout before the responsibility-based Core directory migration. Consult
[the current architecture](../architecture.md), [public API guide](../api-2.md)
and [test instructions](../TESTING.md) for current references.

Do not rewrite historical test results to imply they were rerun against a
reorganized source tree. Produce a new verification report after actually
building or testing a new release revision.
